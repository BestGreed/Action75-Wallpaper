# 灯历 · 八式焰花

将 `lantern-almanac` 作为一个文件夹导入。包内 8 个 Effekseer CPU 粒子资源共用一张 64×64 的渐变光点纹理。每次触发以按键位置为局部原点。作品默认全部勾选、顺序播放、每键一次。作者在 settings.json 的 playback.order 数组指定顺序。用户在控制台可单选或勾选多种花型，在作者顺序和随机播放之间切换，并设为每 1–99 键触发一次。大小、展开速度、亮度的声明绑定分别为 `effectScale`、`effect.speed`、`effectBrightness`。大小与展开速度的范围均为 0.5–2 倍，亮度为 0.25–1 倍，三者默认值均为 1。

|编号|花型|运动设计|
|---|---|---|
|1|玫瑰心笺|44 颗玫红与粉白彗星沿参数心形展开，外缘逐渐减速，星屑从光头脱落。|
|2|金丝垂柳|26 条镜像枝条以不同仰角和重力抛出，内侧弧线更高、寿命更长，金色余烬随后下垂。|
|3|潮汐双环|青色正环先展开，紫蓝斜环延迟四帧跟进，双环相交后暗去。|
|4|剪纸星菊|12 瓣朱砂菊，每瓣由五个长短不同的轨迹描出尖端和两侧。|
|5|青瓷牡丹|三个错角的五瓣波纹花冠以不同半径和时间开出，浅青与淡紫层层交叠。|
|6|翡翠棕榈|先抽出明亮主干，七根绿叶柄从顶端分叉，每根带四条细尾。|
|7|棱镜风轮|六组光点从固定方位陆续发射，切向加速度让各组弯成旋叶。|
|8|锦簇花束|五条高低不同的花梗先升起，梢头分别发出九瓣小花。|

每个彗星具有独立速度、加速度、寿命和渐隐时间。其子发射器每三帧留下光点，以生成时的父位置为起点缓慢下落。约三分之一彗星在熄灭前另放出一颗具有 24 帧寿命的晚期余烬。粒子使用内置加法材质。八种轨迹、纹理、封面、播放选项和参数清单均由本作品的 `build.py` 生成。封面是三种主花型的轨迹插画。

## 修改与重建

`projects` 中的八个 .efkproj 可以在 Effekseer 1.80.8 内打开。纹理与工程放在同一目录。可直接改工程并导出对应 .efk 到发布包。若选择脚本工作流，请修改 `build.py` 中的 `paths`、`emitter_origin` 与各发射器参数。重新运行脚本会重新生成工程和发布资源。

在安装有 Python、Pillow 和 Effekseer 1.80.8 的 Windows 环境下运行：

```powershell
python build.py --editor <Effekseer.exe>
python verify.py --player <Action75Native.exe> --preview <技能目录/scripts/preview.py>
```

使用同一编辑器重建两次，发布目录的 12 个文件 SHA-256 按文件一致。项目定义与运行资源均可随作品离线保存。效果只引用包内的 spark.png。

## 作者实测

固定播放器 SHA-256 为 `7022b112fada97cda3c24c93f4e45203d9bdf638914999fbf06d600d028a8d96`。完整包及八种分别隔离的资源均通过技能提供的六帧离屏试播。全画幅 PNG 和各自亮点边界记录在 `evidence`。单资源诊断在临时目录仅改变清单候选，不改二进制。所有图像均为播放器直接回读，分辨率 1920×720。

该固定版本的试播只提供一次触发与第六帧，不能凭这些 PNG 确认多选过滤、顺序、隔键计数、外观滑块、后半程形状或最后消散。完整包的第六帧花型也不能证明它采用清单规定顺序。含通用变体支持的宿主需要另外验证这些行为。作者未接入物理键盘、副屏或用户桌面。

## 花冠大小对照

一级彗星、起焰和花梗继承效果实例的缩放。拖尾颗粒在父粒子的实际发射位置生成。使用技能的 trace.py、同一心形和 KeyG 分别触发两次独立会话，第 430 毫秒的真实回读结果如下。包围盒采用 RGB 非黑像素，右、下界不包含在内。

|花冠大小|包围盒（左，上，右，下）|像素宽 × 高|
|---|---|---|
|0.5 倍|709，400，769，455|60 × 55|
|2 倍|627，342，852，547|225 × 205|

两档宽度相差 3.75 倍。对应回读在 evidence/scale-0.5 与 evidence/scale-2。软件渲染宿主 SHA-256 为 3d97eaa3fed69e8fa2758df303658b05661c46969bf1883bcb5d8c17bc803c88 。trace.py 按墙钟时间发起截图，重复采样可能落在相邻动画帧。
