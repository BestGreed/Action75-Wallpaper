# Action75 产品说明

<!-- impeccable:product-schema 1 -->

## Platform
Windows desktop, Rust/egui manager and C++/D3D11 player.

## Users
Action75 keyboard owners using its 1920×720 display in extended mode.

## Product Purpose
Install, choose output and keyboard, then use responsive interactive wallpapers.

## Capabilities and Constraints
Confirmed requirements are maintained in docs/product-decisions.md. The native library uses the approved 外壳刻线 visual design. Single-click activates a wallpaper. Foreground and background have independent basic and advanced controls. Only 60 FPS is exposed. Calibrations and user settings survive upgrades. Diagnostic and development copy must not appear in release UI.
