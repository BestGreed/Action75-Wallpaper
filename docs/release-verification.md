# 0.3.1 交付验证

## 水彩参数修正

颜料浓度仅调整线性颜色的吸收深度，不再进入中心、边缘侵蚀和透明度计算。喷溅大小独立控制几何缩放，并放在常用参数中。亮度移除会抵消增益的峰值归一化，85 为中性值；浓度 40 为中性值。现有保存的三个参数数值保持不变。

新增 WARP 离屏像素测试：九组喷溅在同一动画时刻调节浓度或亮度时，逐像素 alpha 完全一致，颜色明度按预期变化；改变大小则改变覆盖范围。测试同时验证实际 settings.json 的三个参数独立绑定。可编辑材质源在 `native/windows-player/materials/paintball`，运行 `python tools/compile-paintball-materials.py` 写回材质包，无新增纹理、绘制调用或全屏处理。

## 实现

- Eagle 风格壁纸库、真实缩略图、自适应网格、可收起且记忆状态的参数面板。
- 10 款壁纸，前景与背景独立、常用与高级控件由壁纸配置声明。
- 60 FPS 单一输出设置，输入不绕过帧率上限。
- 校准拟合确认、预览和撤销，手动保存；采用参考键位的仿射拟合并保持当前点集的外接范围。
- 目录迁移在工作线程复制与逐块校验，成功重载后才清理旧文件。发生冲突或重载失败保留原目录；不迁移无关文件，清理前再次检查源文件是否变化。
- 两进程诊断日志按 10 MB 轮转，共保留 10 份。参数拖动预览不写日志或配置文件；停止拖动后提交配置。
- 缓存缩略图文件版本，避免刷新时重复解码和上传；按可见行绘制网格；空闲 UI 按需重绘。
- 托盘自启、关闭面板继续播放、后台启动后管理器退出以释放内存。
- 每个安装目录有独立播放器连接身份；控制面板单实例。

## 验证范围

Rust release 测试包含校准拟合的真实 egui 按钮确认/取消/撤销、日志轮转、目录冲突/失败回滚及旧有配置并发回归。
原生测试重新编译；附加跨进程配置集成检查独立参数、重启持久化及扩展控件。
安装包在隔离目录实际安装和重复安装，检查偏好及校准保留。硬件离屏渲染逐款施加每秒约 40 次触发，测量帧间隔、CPU 提交、GPU 时间和工作集；每款测量约 4 秒。

最终压力测量为 59.83–60.20 FPS，播放器工作集约 61–107 MB；水彩为 60.14 FPS，GPU 时间 p95 约 2.22 ms。结果仅代表当前机器的短时离屏负载，不代表所有显卡、长时间游戏共存或真实按键到屏延迟。

最终 Rust release 测试 100 项、原生测试 8 项通过。隔离安装、重复安装与卸载检查通过；卸载保留用户数据。上一版界面审核对面板状态记忆、滑条形态、配色工具密度三项修复给出 `ship`，该结论仅覆盖这三项修复。
