# ADR-0001：建立独立工作区渐进迁移

## 状态

Accepted · 2026-11-17

## 背景

源码、部署和实验产物分布在不同目录。用户授权安装技能并开始开源重构。
现有配置与物理校准具有实机价值，需要在每一阶段可验证地保留。

## 决策

建立独立 Git 工作区，复制当前管理器和播放器源码并记录逐文件哈希。
先建立回归基线与可移植构建入口，再按候选逐步迁移。
第一阶段保留现有双进程技术栈，不在分析阶段加入动态插件或更换 UI 框架。

## 考虑过的选项

- 直接整理运行目录：容易混淆部署文件与源文件，回退成本较高。
- 整体重写：失去已有测试与故障恢复机制，验证范围过大。
- 独立工作区渐进迁移：便于比较与回退，但需维护来源清单并逐步接通构建。

## 后果

原运行版本可保持可用；新工作区尚不可直接发布。
迁移期间要防止两份源码分叉，后续改动集中在新工作区，旧源只作基线参考。
