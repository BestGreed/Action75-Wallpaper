# 从参考到实渲染

[返回制作入口](README.md) · [预览与验收](verification.md)

## 做出可比较的样片

1. 先看实物照片、真实运动或成熟作品，提取构图、材质、配色和时间变化。例如水面需要反射随坡度移动，菊形烟花依靠放射拖尾识别。把参考图、原创素材、生成素材及其来源记录下来。生成图可以用于构图、底图或初始形态，实时画面仍由当前后端合成。
2. 在 1920×720 内分别排好待机画面、首次可见、峰值、收尾。键盘屏较矮，留意长尾和大圆是否被切成难以识别的形状。压低按键热点附近的背景对比，缩到壁纸库尺寸再比一次可读性。看实机时同时检查透明键帽、轴体遮挡和黑边。
3. 选两三种视觉方向时，保持输入位置、时刻和画幅一致。一次对比一项，例如用同一轨迹比较两套烟花配色。让形状、尺寸、角度、透明度或持续时间有可控变化，固定随机种子复现问题。
4. 从单键短片开始，再看连按和多键。先修起亮、受力和收尾的连贯性，再加拖尾、微粒与辉光。把「太生硬」定位到可改的环节，例如第一帧过亮、同键重置导致闪跳、序列帧轮廓跳动或淡出曲线末尾突然断掉。

## 按效果拆解

### 水面与涟漪

先决定呈现平静水面还是流动颜料。局部图集足以表达一圈短闪。多处波纹共享水面时，沿用「水波」的原生路线。触点给波场一个有尺寸的扰动，固定步长传播，相遇时叠加。让法线改变反射和折射，边缘逐渐吸收，能量降低后恢复平静。`WaterSurface` 用两张 GPU 纹理交替保存波面状态，限制补算步数，合并待处理触点。优先调触水力度、范围、传播和消散，再比较不同水面背景的高光和水底光纹。实看单键从中心发出几道可辨波峰、相邻键波纹交汇、边缘无异常回卷和停止后平息。 [WaterSurface.cpp](../../native/windows-player/src/WaterSurface.cpp) · [水波参数](../../wallpapers-native/stillwater/settings.json)

### 烟花

对照真实花型做轮廓与时间差。牡丹用亮点撑出圆团，菊花用放射的发光拖尾，垂柳靠较慢的下坠长尾，土星靠不同倾角的环。为每个预设定义粒子初速、方向分布、拖尾、下坠、亮梢变色和二次绽放。粒子、拖尾与辉光用有界的批量绘制，密集时优先保留主花和爆点。「烟火」的播放花型区用勾选框统一调整固定花型与组合轮换。达到设定的击键次数时，烟花从当次按键的校准坐标绽放。测试同花型不同配色、连续触发、最后一项勾选的反馈，以及屏幕边缘。 [烟火参数](../../wallpapers-native/night-fireworks/settings.json)

### 黑洞与发光体

先画黑洞阴影、吸积盘和背后的透镜层，再处理按键恒星。用同一中心和缩放计算拖动命中、阴影覆盖与透镜，边缘构图允许半个主体出画。恒星亮核锚在键位，盘面区域的余辉沿流向变化。连续击键可积累热脉冲，亮度先升后降，避免为同键替换整颗星。验证阴影内静默、阴影移开可触发、中心与极限尺寸能保存。鼠标交互与独占模式下的参数控制都走正常入口。 [BlackHoleScene.cpp](../../examples/native-wallpapers/black-hole/src/BlackHoleScene.cpp) · [黑洞参数](../../wallpapers-native/black-hole/settings.json)

继续做近盘光路时，先约定光源相对盘和阴影的位置。根据透镜反向查找光源，评估遮蔽、弧形次像与亮度随位置的变化。共享场景的中心和尺度，用同一触发序列对照盘外、盘沿和盘后的光路。把这种近似的范围记录在实现说明中。 [BlackHole.hlsl](../../examples/native-wallpapers/black-hole/src/BlackHole.hlsl)

### 喷溅、冰晶与局部材质

水彩的颜色深度、亮度、整体飞溅范围、中心水波大小、滞留和淡出各有用途。调整浓度时用同时间帧比较颜色和轮廓，调整大小时只检查目标覆盖范围。像素水花可先计算相邻液滴与薄膜，再在最终外观像素化，避免粒子各自成团。冰晶可以从六角结构推导主枝、侧枝与晶面，生长、增厚、反光、融薄要按阶段变化。单键局部材质还需要遮罩和边界检查，比较短键、空格和边缘键。 [水彩参数](../../wallpapers-native/paintball-native/settings.json) · [键影](../../wallpapers-native/keycap-glow/manifest.json)

### 玻璃碎裂

让主裂纹从受力点向外生长，把短分叉集中在击点附近。沿主裂纹划出大小不一的透明玻璃片，错开相邻片的接缝端点，让反光只在少数断面出现。「碎光玻璃」每次触发随机取样力度，同键连按沿用已有裂纹图样。中心破碎范围控制玻璃片的大小，裂纹范围控制向外延伸的主裂纹。用固定种子、位置和力度分别渲染三档大小，并在极夜蓝、琥珀暮光和银雾下检查轮廓。 [碎光玻璃着色器](../../native/windows-player/materials/GlassShatter.hlsl) · [玻璃探针](../../native/windows-player/tests/glass_shatter_tests.cpp)
