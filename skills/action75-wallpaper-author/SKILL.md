# 制作 Action75 互动壁纸

交付一个可导入的作者文件夹。播放器提供按键位置、输出设备和帧调度；作品定义看到什么、按键如何改变场景、哪些参数允许用户调整。

## 选一条实现路线

| 想做的作品 | 从哪里开始 |
|---|---|
| 在按键处播放一次独立的手绘动画，例如光环或墨迹 | 跟做[第一款壁纸](references/workshop.md)。用随附脚本生成图集、背景和两个 JSON，再换成自己的美术。 |
| 同时发射许多粒子，需要各自的轨迹、重力、寿命或子发射器 | 用 Effekseer 制作资源，按[作者接口](references/pack.md)导出兼容的 CPU 粒子；有多个作品变体时再读[播放规则](references/playback.md)。 |
| 组合播放器已有的烟火花型 | 用 `fireworks` 和[播放规则](references/playback.md)。作者自己设计的花型可走粒子、图集或原生路线。 |
| 需要持续状态，例如磁液吸附、角色移动、游戏分数、按住与松开，或自写着色器 | 走[原生插件制作](references/native.md)。D3D11 使用 ABI 1；D3D12 使用 ABI 2 和作者自己的着色器。先编译对应示例，再替换场景、输入和绘制逻辑。 |

## 设计画面和参数

先写出一次可观察的交互。例如“按下时液体向键位聚拢，松开后缓慢回流”。再列出画面中可独立调整的对象，以及每个参数应该改变的对象。这样能提前判断图集能否表达效果，也能确定试播要抓哪些时刻。

多主体作品按对象组织面板，如“磁流体、磁场、底板”；简单作品可用“前景、背景”。基础设置放样式、亮度、色相、饱和度和颜色，高级设置放运动、物理与交互规则。具体字段、合并顺序和条件显示见[参数分组规范](references/pack.md#参数分组)。升级已有作品时保留包 ID、控件 ID 和既有值的含义。

## 制作和交付

1. 为新作品建立独立目录。根目录放 `manifest.json`，清单指向参数文件和运行素材，资源使用包内相对路径。把可编辑源工程、构建目录与验收截图放在成品目录旁边。
2. 先做一个完整动作。用 `scripts/preview.py` 离屏加载包并保存真实帧，再用 `scripts/trace.py` 固定键位与采样时刻比较设置。两者都需要匹配版本的 Windows 播放器。可直接执行的命令见[从生成到验收](references/workshop.md)。
3. 逐项检查面板与画面，测试连续触发、参数极值、效果结束后的空闲状态。对原生作品加测按键释放、输入重置和暂停恢复。需要对比性能时，记录相同分辨率、设备、播放时长和输入负载下的播放器与 Worker，分开记录空闲和交互阶段。
4. 将成品文件夹复制到另一个位置，在独立测试库用控制台“导入”选择含清单的那一层。重新选择该作品，确认素材、输入与保存的设置均能恢复。交付时说明宿主版本或哈希、作品操作、已验证的环境和范围。

遇到“能导入但没画面”“滑块能拖但没变化”或“静止仍持续绘制”，按[故障现象](references/workshop.md#遇到问题)逐步区分资源、面板声明、输入与渲染问题。
